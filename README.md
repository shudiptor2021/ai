This is a modern **AI-powered full-stack web application** built with **React 19**, **Node.js**, **Express**, and **MongoDB**. It delivers a fast, scalable, and responsive user experience with secure authentication, AI integration, cloud-based media storage, and efficient state management.

### 🖥️ Frontend

- ⚛️ **React 19** with **Vite** for lightning-fast development
- 🔀 **React Router DOM** for seamless client-side routing
- 🎨 **Tailwind CSS v4** for a responsive and modern UI
- 🔐 **Clerk Authentication** for secure user management
- ⚡ **React Query** for data fetching, caching, and synchronization
- 🌐 **Axios** for REST API communication
- 🔥 **React Hot Toast** for real-time notifications
- 📝 **React Markdown** for rendering AI-generated Markdown content
- 🎯 **Lucide React** for clean and modern icons

### ⚙️ Backend

- 🚀 **Express.js** REST API
- 🍃 **MongoDB** with **Mongoose**
- 🤖 **OpenAI API** integration for AI-powered features
- 🔒 Secure authentication with **Clerk Express**
- 🔔 **Svix Webhooks** for Clerk event handling
- ☁️ **Cloudinary** for image storage and optimization
- 📤 **Multer** for file uploads
- 📄 **PDF Parsing** using **pdf-parse-fork**
- ✅ **Joi** for request validation
- 🌍 **CORS** support
- 🔑 Environment management with **Dotenv**
